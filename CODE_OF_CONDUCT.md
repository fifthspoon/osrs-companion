# Code of conduct

Short version: be decent, argue about the code rather than the person, and
assume the other person is trying.

This is a small project. It does not need a legal document, it needs everyone to
know where the line is and who decides. So this is written plainly rather than
copied from a template.

## What is welcome

- Blunt technical disagreement. "This is wrong and here is why" is not rudeness,
  it is the entire point. Being told your idea is bad is not a personal attack.
- Saying you do not know something, or that you did not test something. Nobody is
  penalised for admitting a gap. Confidently claiming something works when you
  never checked is worse for this project than any bug.
- Questions that feel obvious. If the docs made you guess, that is a docs problem
  and worth reporting.

## What is not

- Insults, harassment, or going after someone's identity: race, sex, gender,
  sexuality, disability, religion, nationality, age, any of it.
- Sexual content or unwanted sexual attention.
- Following someone from thread to thread to keep having the same argument.
- Publishing anyone's private information.
- Deliberately wasting people's time. Spam, endless bad faith rehashing, and
  pull requests submitted to make a point rather than to change the code.

Swearing is fine. Swearing *at someone* is not. The difference is obvious in
practice and I am not going to pretend it needs defining.

## Where this applies

Issues, pull requests, discussions, commit messages, and anywhere else connected
to this project.

## Who decides, and what happens

The maintainer decides, and the decision is not up for debate in a public thread.
Depending on how bad it is: a comment gets deleted, a thread gets locked, or an
account gets blocked from the repository. Serious or repeated behaviour skips
straight to the block.

The aim is to keep this a place where blunt technical argument is comfortable,
which does not survive if people are being dicks to each other.

## Reporting

Open a private report through GitHub by contacting
[@fifthspoon](https://github.com/fifthspoon) directly. If the problem is a public
comment, a link to it is enough. Reports are read by the maintainer only and are
not discussed publicly.

If the person you need to report is the maintainer, GitHub's own abuse reporting
exists for exactly that, and using it is a legitimate move rather than an
escalation.
